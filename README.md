# Ilyes Laaradh — Personal Cybersecurity Portfolio

Live site: https://laaradh.com

A bilingual personal portfolio focused on computer science, cybersecurity and offensive security.

## Stack
- HTML
- CSS
- Vanilla JavaScript
- GitHub Pages
- Cloudflare DNS
- Custom domain: `laaradh.com`

## Structure
- About
- Projects
- Write-ups
- Experience
- Certifications
- Skills
- Contact

The site uses a lightweight client-side EN/FR language switcher. Content is intentionally easy to extend as new projects, labs, certifications and experiences are added.

## Deployment
GitHub Pages deploys the `main` branch. The custom domain is configured through GitHub Pages and Cloudflare DNS.
